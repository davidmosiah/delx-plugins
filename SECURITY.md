# Security

These plugins contain no executable code — only skill instructions (Markdown)
and MCP server declarations pointing at `https://api.delx.ai`.

- The `delx-recovery` MCP endpoint is free and requires no credentials.
- The `delx-commerce` MCP/x402 endpoints charge per call via HTTP 402; no API
  keys are stored or requested by the plugin.
- Report vulnerabilities in the hosted service to security@delx.ai. Do not
  open public issues for security reports.
